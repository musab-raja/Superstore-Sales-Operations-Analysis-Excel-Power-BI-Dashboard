# Superstore-Sales-Operations-Analysis-Excel-Power-BI-Dashboard
Recently completed an end-to-end Business Intelligence project using the Superstore dataset — built entirely in MS Excel, with the final dashboard visualized in Power BI.
Cleaned & standardized raw sales data in Excel (removed duplicates, normalized dates/text)
🔹 Built calculated fields in Excel for Sales, Profit, Discount & Quantity analysis
🔹 Created a Sales Target table in Excel (planning assumption, +8% above historical baseline)
🔹 Prepared a monthly Forecast dataset in Excel for trend analysis
🔹 Connected the cleaned Excel data to Power BI and designed KPI cards, regional/category breakdowns & sales trend visuals
Workflow: Raw Data → Cleaning (Excel) → Calculated Fields (Excel) → Sales Target & Forecasting (Excel) → Power BI Dashboard
This project helped me strengthen my Excel data preparation and Power BI dashboard storytelling skills.
